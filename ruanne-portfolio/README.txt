# Portfólio Ruanne Josefa

## Como visualizar

### Opção 1 — mais simples
1. Extraia o arquivo ZIP.
2. Entre na pasta `ruanne-portfolio`.
3. Dê dois cliques em `index.html`.
4. O portfólio abrirá no navegador.

### Opção 2 — VS Code (recomendado para editar)
1. Instale o Visual Studio Code.
2. Abra a pasta `ruanne-portfolio`.
3. Abra `index.html`.
4. Instale a extensão **Live Server**.
5. Clique com o botão direito em `index.html`.
6. Selecione **Open with Live Server**.

O navegador abrirá o site e atualizará automaticamente quando você salvar alterações.

## Onde editar

- `index.html`: textos, seções, links e conteúdo.
- `style.css`: cores, fontes, tamanhos, espaçamentos e layout.
- `script.js`: abas de competências, modal dos projetos e navegação.
- Substitua os blocos `photo-placeholder` por suas fotos reais.

## Personalização rápida

Procure no `index.html` por:
- `sua foto principal`
- `foto / paisagem do Maranhão`
- `foto`
- `sua foto`
- `uma memória`

Depois podemos transformar esses espaços em imagens reais.

Também substitua:
- `seuemail@example.com`
- `https://www.linkedin.com/`
- `https://github.com/`
- `https://instagram.com/`

por seus links reais.

## Observação

O projeto usa Google Fonts, então é necessária internet para carregar as fontes. O restante do site funciona localmente.
